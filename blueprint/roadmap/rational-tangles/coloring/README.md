# The fraction through integral coloring

This nested chapter is the execution plan for Conway's classification:
Kauffman–Lambropoulou §5. Color the arcs of a rational tangle by integers
so that under-arcs $\alpha,\gamma$ and over-arc $\beta$ satisfy
$\alpha+\gamma=2\beta$. The resulting color matrix determines a quantity
$f(T)$ which is a topological invariant, obeys the same arithmetic as the
continued-fraction fraction $F(T)$, and equals $F(T)$. Theorem 2 (that $F$
is an isotopy invariant) follows from $f$ being invariant and $f=F$, without
the Tait flyping conjecture. Combined with §§2–3 and Theorem 3 this proves
Theorem 1.

The paper calls Reidemeister (and flype) invariance of the coloring "easy to
verify". Those verifications are listed below as lemmas to prove, not as
axioms.
