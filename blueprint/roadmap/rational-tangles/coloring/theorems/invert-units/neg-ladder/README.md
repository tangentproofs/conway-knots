# Negative invert-add ladder

Per-rung values of the negative unit ladder: `([-1]×n)ⁱ` carries `-1/n`.
Each rung is proved directly — the switched rules force numerator `d`
and denominator `-nd` — with the `neg_ne_zero` pattern for the negative
denominator multiple, one pull-request-sized node each (the six-unit
rung is split into universal and existence nodes for size; the ten-unit
rung and above additionally factor their rule equations into a shared
preliminaries node so each universal stays under the span limit, and live
in the [factored-rungs sub-chapter](factored-rungs/README.md), continued
in [factored rungs two](factored-rungs-two/README.md),
[factored rungs three](factored-rungs-three/README.md),
