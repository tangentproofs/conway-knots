# Negative invert-add ladder: factored rungs three

Rungs twenty-four and above of the negative unit ladder, each split into rule
preliminaries, universal, and existence nodes (the flat universal would
otherwise exceed the span limit). Opened as the sequel of the
[factored-rungs-two sub-chapter](../factored-rungs-two/README.md): a further
quartet cannot fit there (21 + 4 = 25 > the 24-article limit), so new rungs
go here; the mathematics is unchanged.
