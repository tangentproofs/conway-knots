# Negative invert-add ladder: factored rungs six

Rungs thirty-five and above of the negative unit ladder, each split into
crossings preliminaries, a fraction-value preliminary, universal, witness,
witness-rules, existence, and (from rung thirty-six) witness-value nodes
(the flat universal would otherwise
exceed the span limit, and from rung twenty-nine the universal linarith tail is
factored out the same way; from rung thirty-six the existence tail is factored
likewise). Opened as the sequel of the
[factored-rungs-five sub-chapter](../factored-rungs-five/README.md), which
holds 19 articles (a sextet cannot fit there: 19 + 6 = 25 > 24),
so new rungs go here; the mathematics is
unchanged.
