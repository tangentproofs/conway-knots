# Negative invert-add ladder: factored rungs four

Rungs twenty-nine and above of the negative unit ladder, each split into
crossings preliminaries, a fraction-value preliminary, universal, witness,
witness-rules, and existence nodes (the flat universal would otherwise
exceed the span limit, and from this rung the universal linarith tail is
factored out the same way). Opened as the sequel of the
[factored-rungs-three sub-chapter](../factored-rungs-three/README.md), which
is at the 24-article limit, so new rungs go here; the mathematics is
unchanged.
