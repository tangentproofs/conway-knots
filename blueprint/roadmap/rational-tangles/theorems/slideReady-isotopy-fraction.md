# Standard-form $F$ along slide-ready coloring paths

`SlideReadyIsotopy` is the directed relation generated by `ColoringIsotopy`
between `slideReady` twist diagrams together with the leftover generators
already compared at the coloring fraction on that class: invert-congruence,
invert-add and invert-mul of a unit, mirror-congruence, and Figure 14
(`transfer_odd`). A carried value is a coloring fraction of both endpoints.
Intermediates need not be twist-form.

If both endpoints *are* `slideReady` twist diagrams, uniqueness of $f=F$
identifies the carried value with each expression's `toStandard.fraction`,
so those standard-form values agree. The same conclusion holds for
standard-form expressions via `toTwist`.

This is not Theorem 2 and not full `Isotopic`. Diagram isotopy can leave the
twist/`slideReady` class; the relation also omits `flype_slide_*`,
`rot180_*`, `transfer_odd_neg`, and invert-add of two general summands.
None of those leftover constructors is added to `ColoringIsotopy`.
