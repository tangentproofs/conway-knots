# The toStandard path and standard forms

Recoloring a `slideReady` twist along the explicit `toStandard` steps
(planar isotopy, add/mul congruence, Figure 5 slides under `DiagonalSum`,
`rot180`) preserves the color matrix, hence identifies $f$ with the
standard-form value. Existence versions via `colorFrom`, and the
standard-form invert transport (fresh coloring of $T^{i}$ carries
$F^{-1}$). Proof part of the parent topic; see that page for the
mathematical context.
