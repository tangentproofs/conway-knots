# Same fraction implies isotopic diagrams with agreeing colorings

On `slideReady` twists with unit fractions, same algebraic fraction
gives isotopic diagrams *plus* non-monochrome colorings of both
carrying the common standard value (via `colorFrom` and unconditional
$f=F$; the standard values agree through the normalized forms). This
closes the Theorem-3/coloring loop on the proved fragment. Arbitrary
parses and arbitrary rational diagrams remain outstanding.
