# Rational tangles

This blueprint formalizes Conway's classification of rational tangles, following
the integral-coloring proof of Kauffman and Lambropoulou §5 together with the
form lemmas of §§2–3 and Theorem 3. The present milestone is a single theorem:
two rational tangles are isotopic if and only if they have the same
continued-fraction fraction. Tait flyping is not used.

The [coverage notes](coverage/README.md) keep this local progress distinct from
the Conway census of knots and links, which is out of scope.
